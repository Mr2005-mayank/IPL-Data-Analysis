# 🏏 IPL Data Analysis Dashboard

An interactive web dashboard to analyze **IPL (Indian Premier League)** match and player data — built with **Python, Pandas, NumPy, Streamlit, and Plotly**.

🔗 **Live Demo:** _Add your deployed Streamlit link here_

---

## 📖 About

This dashboard explores IPL match history and delivery-level data to uncover insights on team performance, season trends, batting, bowling, and individual player stats — all through interactive charts and filters.

---

## ✨ Features

- 📊 **Overview** — Key stats at a glance (matches, runs, sixes, fours, wickets)
- 🏏 **Batting Analysis** — Player and team batting performance breakdown
- 🎯 **Bowling Analysis** — Wickets, economy, and bowler performance insights
- 👤 **Player Analysis** — Deep-dive stats for individual players
- 🏆 **Team Performance** — Team-wise wins across seasons
- 📅 **Season-wise Trends** — Matches played per season
- 🔎 **Interactive Filters** — Filter data by season and team
- 🥇 **Match Result Distribution** — Breakdown of match outcomes

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- pip

### Installation

```bash
# Clone the repository
git clone https://github.com/Mr2005-mayank/IPL-Data-Analysis-Dashboard.git
cd IPL-Data-Analysis-Dashboard

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

The dashboard will open in your browser at `http://localhost:8501`
